# Пример дневника мочеиспусканий: один полный день, строка за строкой
Source: https://fluidbalanceapp.com/ru/blog/bladder-diary-example/
Published: 2026-09-28 · Статья · Denis Zinin, разработчик приложения Дневник мочеиспусканий: Fluid Balance. Не врач.

Коротко:
Ниже разобран пример дневника мочеиспусканий за один полный день, строка за строкой: около пятнадцати записей, где у каждого питья есть объём, у каждого похода — объём или отметка «не измерено», есть время отхода ко сну и подъёма и заметка там, где что-то случилось. День выдуман, поэтому его суммы — не цели. Раскладка повторяет дневник Urology Care Foundation и бланки NHS, в собственных формах которых показаны одна-две строки примера. Что этот день должен показать:

- Полный день дневника — это примерно пятнадцать строк: каждое питьё с объёмом, каждый поход с объёмом или отметкой, время отхода ко сну и подъёма и заметка там, где что-то случилось.
- Пример ниже — выдуманный день. Его суммы не цели, и сравнивать их здесь не с какой нормой.
- Врач читает в нём число походов днём и ночью, объёмы, распределение питья, заметки и то, полный ли день.

В бланках клиник показывают одну-две строки примера: в дневнике Urology Care Foundation это одна строка с банкой газировки и подтеканием при смехе,[1] в бланке NHS Gloucestershire — утро с чашкой чая и подтеканием,[2] в физиотерапевтическом бланке Сассекса — три утренние строки с суммами.[3] Полезно, но ни у кого день не длиной в три строки. Вот целый выдуманный день в формате нашего [шаблона для печати](https://fluidbalanceapp.com/bladder-diary-template/), а следом — что каждая его часть говорит врачу. Числа здесь принадлежат только этому примеру; никакой нормы, с которой их можно было бы сравнить, на этой странице нет.

## Как выглядит полный день дневника

Заполненный пример дневника мочеиспусканий. День 1 из 7. Лёг в 22:45. Встал в 7:00.

| Время | Выпито (мл) | Что | Выделено (мл или ✓) | Ночь | Заметка |
|---|---|---|---|---|---|
| 7:05 | | | 350 | | первый утром |
| 7:20 | 250 | чай | | | |
| 8:30 | 200 | кофе | | | |
| 9:40 | | | ✓ | | спешил, небольшое подтекание |
| 11:00 | 500 | вода | | | |
| 11:45 | | | 220 | | |
| 13:10 | 330 | сок | | | |
| 13:30 | | | 180 | | сильный позыв |
| 15:00 | 250 | чай | | | |
| 16:20 | | | 260 | | |
| 18:00 | 250 | вода | | | |
| 19:30 | 200 | пиво | | | |
| 20:15 | | | 300 | | |
| 22:30 | | | 150 | | перед сном |
| 3:10 | | | 180 | ✓ | |

Пятнадцать строк, одна страница. Сутки идут от подъёма до подъёма, поэтому поход в 3:10 относится к дню 1, хотя дата уже сменилась.

## Строка за строкой

**7:05, 350 мл, «первый утром».** Первый поход после подъёма. Не ночной, потому что ночь дневника закончилась в 7:00, но по определению ICS выделенная тогда моча образовалась за ночь и прибавляется к ночному объёму,[5] — поэтому её измеряют, а не отмечают галочкой. На бумаге это просто первая строка дня.

**7:20 и 8:30, чай и кофе.** Напитки с объёмом и видом. Объём взят из того, что кружку один раз измерили; вид указан, потому что бланки клиник его спрашивают.[1,2]

**9:40, галочка, «спешил, небольшое подтекание».** Измерять было некогда, поэтому галочка вместо объёма, и поход всё равно идёт в счёт походов за день.[2] Заметка фиксирует подтекание с примерным размером. В бланке со столбцами для подтекания это было бы «небольшое» или «+»; в простом дневнике — заметка со временем.

**11:00, 500 мл воды.** Бутылка, объём напечатан на ней.

**13:30, 180 мл, «сильный позыв».** Измеренный поход с отмеченным позывом: внезапное, трудно сдерживаемое желание.[4] Записано сразу, в два слова, и этого достаточно.

**19:30, 200 мл пива.** Алкоголь на листе — такой же напиток: объём, вид, время. Дневник должен показать обычный вечер, а не прибранный.

**22:30, 150 мл, «перед сном».** Последний поход до времени отхода ко сну, записанного наверху страницы. Это дневной поход; ночь начинается в 22:45.

**3:10, 180 мл, отмечено «Ночь».** Между тем, как легли, и тем, как встали, — значит, галочка. Именно эта строка делает возможным ночной счёт; дневник без времени отхода ко сну и подъёма не отличит этот поход от того, что в 22:30.

## Что складывается за этот день

Только потому, что пример это позволяет: 1 980 мл выпито за семь напитков; 1 640 мл выделено за семь измеренных походов плюс один поход с галочкой без объёма; всего восемь походов, один из них ночью. В бланке клиники вас могут попросить записать эти суммы в нижнюю строку; в приложении они появляются на экране дня и в отчёте без всякого сложения. Это не цели, и они ни для кого в отдельности не типичны. Их единственная задача здесь — показать, как выглядит полный день, когда его посчитали.

## Что видит в нём врач

Восемь походов со временем, один ночной, один без измерения. Семь измеренных объёмов, от 150 до 350 мл. Питьё распределено с 7:20 до 19:30, виды записаны. Две заметки: подтекание с поводом и позыв. Время отхода ко сну и подъёма — чтобы отделить ночь от дня. И день, полный от пробуждения до пробуждения: это первое, что проверяют, потому что одна память путает даже число походов.[6] Что эти факты значат — вопрос приёма; задача дневника была их принести.

## Ваш день будет другим

Строк больше или меньше, другие напитки, другое время. Неизменным остаётся формат: каждое питьё, каждый поход, объём или галочка, две отметки времени, обрамляющие ночь, и заметка там, где что-то случилось. ## Вопросы

**Куда записывать первый утренний поход?**
Первой строкой нового дня, после времени подъёма, с объёмом, если вы его измерили. Это не ночной поход, потому что вы уже встали, но по определению ICS выделенная тогда моча образовалась ночью и относится к ночному объёму, так что измерить её стоит. Разбираться с этим — дело врача.

**Нужно ли самому считать суммы?**
Нет. В бланках клиник есть строка итогов, и кое-где её просят заполнить, но врач может сложить и сам; бланк NHS так и пишет. Если вы пользуетесь приложением, суммы, число походов и ночной счёт считаются за вас. Чего делегировать нельзя — это сами строки.

**А если у меня в дне двадцать строк?**
Берите следующую страницу и продолжайте. День с множеством строк — это полный день, а только такой врачу и нужен; выбрасывать строки, чтобы влезло, — вот это ошибка. В нашем шаблоне на A4 24 строки на странице, а в приложении ограничений нет.
